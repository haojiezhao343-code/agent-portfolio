Core Capabilities

核心能力

LangGraph 运营工作流

商品上下文 → 诊断 → 创意策略 → 质量审核 → 人工审核，五步状态机推进，执行过程实时可见。

商品上下文→ 诊断→ 创意策略→ 质量审核→ 人工审核

ToolGateway 统一工具网关

收敛竞品监控、创意方案、广告推荐、库存建议等 7 类运营工具，租户 / 角色 / 租约 / 幂等四重管控。

四平台竞品监控

抖音 / 淘宝天猫 / 拼多多 / Amazon 适配器抓取竞品快照，自动对比变化并生成监控报告。

多模态素材生成

对接 DashScope / 即梦双供应商，打通「文案 → 图片 → 视频」生成链路，产出可直接投放的创意素材。
